# Reference

Source documents this system was built from. Read them when a value here needs checking; do not build from them directly.

| file | what |
| --- | --- |
| `ti-dlp-brand-and-logo-guidelines.pdf` | TI DLP® Brand and Logo Guidelines (Rev. A, 2026): DLP trademark wording rules, DLP logo clear space ("the width of the letter D"), minimum sizes (60px / 0.875 in; 2 in in print ads; 200px in digital ads), colour/black/white versions, misuse examples, when to use the DLP vs DLP-TI logo. For DLP work only. |
| `ti-dlp-logo-usage-end-products.pdf` | DLP logo usage on end products (2014): positive/negative versions, 1-inch minimum, PMS 300 for the colour version. |

TI's 2026 corporate deck (source of the deck theme colours, Arial, the slide anatomy, the line icons and the title backgrounds) is client-confidential and is not kept here; it stays with Hoffman's TI client files.

TI's 29 original deck icons (`icon-*.png`, 80–230px) live in this group as reference for weight and subject; the working icon set is Fluent (`assets/Icons/`).

Not in the system but used: ti.com's Polaris CSS tokens (`--pl-*`, Oct 2026) for the web palette, controls and type scale; ti.com's `ic-logo.svg` for the signature; TI's media-resources page for the four PNG signatures; TI's signature-and-logo trademark page for the preferred/alternate rule.
