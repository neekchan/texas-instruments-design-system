# Icons

Fluent UI System Icons, regular style, in TI teal. The WHOLE library is vendored at `assets/Icons/fluent/` (every size and style, 20,798 SVGs, MIT, unmodified upstream files from `@fluentui/svg-icons`); the curated TI set sits in this folder ready to place, with 512px PNG renders under `png/` for PowerPoint. Any other icon: `tools/icon.py <name>`. Library: `@fluentui/svg-icons` 1.1.343 (© Microsoft Corporation, MIT); `catalog.json` beside this file indexes all 2988 icon names with their sizes and styles, the CDN pattern (`https://cdn.jsdelivr.net/npm/@fluentui/svg-icons@1.1.343/icons/ic_fluent_<name>_<size>_<style>.svg`) and the TI rules, so any icon in the library is one fetch away.

Stored here (118, each as `<name>.svg` in `teal-deck` #117788 and `<name>-ink.svg` in #333333; single-ink, the colour is the `fill` attribute on the root element): `add`, `airplane`, `arrow_right`, `arrow_sync`, `arrow_trending`, `arrow_up_right`, `battery_charge`, `beaker`, `book`, `bot`, `box`, `branch_fork`, `briefcase`, `building`, `building_factory`, `building_multiple`, `calendar`, `camera`, `cart`, `certificate`, `chart_multiple`, `chat`, `chat_multiple`, `checkmark_circle`, `chevron_right`, `city`, `clipboard_task`, `clock`, `cloud`, `cube`, `cube_tree`, `data_bar_vertical`, `data_pie`, `data_trending`, `database`, `desktop`, `developer_board`, `developer_board_lightning`, `developer_board_search`, `dismiss_circle`, `document`, `document_text`, `drop`, `earth`, `eye`, `flash`, `gauge`, `globe`, `globe_person`, `hand_right`, `hand_wave`, `handshake`, `hat_graduation`, `heart`, `home`, `image`, `info`, `key`, `laptop`, `laptop_settings`, `leaf_two`, `lightbulb`, `lightbulb_filament`, `link`, `location`, `lock_closed`, `mail`, `map`, `megaphone`, `mic`, `microscope`, `money`, `money_hand`, `news`, `paint_brush`, `payment`, `people`, `people_community`, `people_team`, `person`, `person_board`, `person_feedback`, `phone`, `phone_laptop`, `play`, `plug_connected`, `presenter`, `print`, `puzzle_piece`, `question_circle`, `receipt`, `ribbon`, `rocket`, `search`, `server`, `settings_cog_multiple`, `share`, `shield`, `shield_checkmark`, `shield_task`, `speaker_2`, `star`, `subtract`, `tablet`, `tag`, `target`, `temperature`, `thumb_like`, `timer`, `toolbox`, `translate`, `trophy`, `vehicle_car`, `vehicle_truck`, `video`, `warning`, `wifi_1`, `wrench`.

Rules: `regular` style only; `teal-deck` on slides, `ink` or `link` on the web; never red; one library and one colour per surface; above a `deck-caption` label or left of text at `icon-lg`. For PowerPoint use the 512px PNG renders shipped in the template or export from the SVG.

TI's own 29 deck icons are kept under `assets/Reference/` for comparison; their Fluent equivalents are in `catalog.json` under `ti_deck_equivalents`.
